# Repository workflow

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing code or Git history.
Keep each feature/fix in a focused, short-lived branch and PR from current main.
Complete its validation and integration before accumulating unrelated roadmap work.
Preserve meaningful commits and verify GitHub author attribution.
Merge only within the user's authorization and after the exact head passes CI;
never bypass audits. Follow the additional Next.js instructions in apps/web/AGENTS.md.
